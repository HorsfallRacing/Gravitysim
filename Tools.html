What the badges mean, and how to change them

Click any badge to change it, or choose “— remove badge” to clear it. A field with no badge shows + badge — click that to add one. Badges are per concept, so the same field can be measured on one and assumed on another.

  • measured — weighed or measured on this vehicle
  • independent — from an external source (CFD, tyre data), not fitted to a run
  • estimated — judged, not measured
  • fitted — backed out of run data, and therefore contaminated by whatever else that run contained
  • assumed — picked. If a result depends on one of these, it is a hypothesis, not a prediction.

Badges are not decoration: the headline, the waterfall and the breakeven panel all call out how much of a result rests on values marked assumed or fitted.
